# V0.6

- Новый общий рейтинг трейдеров 30/60/90 дней.
- Явные подписи показателей в Telegram.
- Фильтры активный/неактивный/прямой/непрямой.
- Сортировка по объёму, комиссии, балансу, пополнениеам.
- Точный алерт пополнения USDT > заданного порога (по умолчанию 500).
- Дедупликация алерт пополненияов отдельно для каждого Telegram ID.
- Миграция старых пополнений в baseline без массовой рассылки.
- Повторы при временных сетевых сбоях и компактный Telegram error handler.
- Несколько ALLOWED_TELEGRAM_IDS сохранены и протестированы.
- Withdrawal alert не имитируется без подтверждённого API.
